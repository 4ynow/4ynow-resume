# Personal Portfolio / Resume

A clean, responsive personal portfolio website built entirely from scratch to showcase my skills, projects, and background in cybersecurity and full-stack development. 

Built with **pure HTML and CSS**, this project demonstrates a strong grasp of core web fundamentals—utilizing Flexbox, CSS Grid, custom animations, and responsive media queries without relying on external frameworks like Bootstrap or React.

## 🛠️ Built With
* **HTML5** (Semantic structure)
* **CSS3** (Flexbox, CSS Grid, Custom Properties, Animations, Media Queries)
* **Google Fonts** (Roboto Slab, Rubik)
* **Font Awesome** (Icons)

## ✨ Features
* **Fully Responsive:** Adapts seamlessly to desktop, tablet, and mobile screens using CSS Media Queries.
* **Modern Layout:** Utilizes CSS Grid for the skills/projects cards and Flexbox for the navigation and about sections.
* **Smooth Scrolling:** Implemented entirely with CSS (`scroll-behavior: smooth`), no JavaScript required.
* **Custom Animations:** Includes a pure CSS blinking terminal cursor on the hero section and interactive hover states on the project cards.
* **Sticky Navigation:** Keeps the logo and links accessible while scrolling through the page.
